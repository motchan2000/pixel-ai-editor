Get started

From install to your first sprite in a few minutes.

  1. Download and run the installerGet Pixel-AI-Editor-Setup-x.y.z.exe from Releases. The installer is unsigned, so if SmartScreen warns you, click “More info” → “Run anyway”.
  2. Pick an AI service and add your keyIn the “AI設定” (AI settings) panel at the bottom right, choose a service, paste your API key and save. Local servers like Ollama need no key.
  3. Choose a size and describe your spritePick 16, 32 or 64, type a prompt and press “ラフを生成” (Generate). The draft lands on the canvas in seconds to a minute.
  4. Refine and exportFix whatever you like, then press “PNG書き出し” (Export PNG) at 1×, 8× or 16×. Ctrl+Z always takes you back.

Let your AI agent draw (MCP)

The “MCP連携” panel copies a ready-made config for your PC. The installed app runs the MCP server itself — no Node.js needed.

# Most clients (Claude Desktop, Cursor, Windsurf, Gemini CLI…)
{
  "mcpServers": {
    "pixel-editor": {
      "command": "...\\Pixel AI Editor.exe",
      "args": ["...\\mcp-server.mjs"],
      "env": { "ELECTRON_RUN_AS_NODE": "1" }
    }
  }
}

# Then just ask
> Draw a 32×32 treasure chest. Check it,
  then add shading to finish it.

The agent paints whole sprites as a text grid, looks at the result with get_canvas (PNG + grid), and polishes it. Everything appears live in the editor, where you can keep editing and undo step by step.
